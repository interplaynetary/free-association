# Research Commons

This directory contains shared research resources that don't belong to a specific organization.

## Purpose

The commons serves as:
- Repository for community-contributed research
- Shared experimental work
- Policy frameworks and proposals
- Resources that orgs can reference or fork

## Governance

Commons content is community-governed through:
- Issues and discussions
- Pull requests with community review
- Consensus-based decisions

## Organization

- `experiments/` - Experimental research and prototypes
- `proposals/` - Major proposals (like DPIv6)
- `policy-frameworks/` - Shared policy frameworks
- `templates/` - Reusable templates
- `tools/` - Shared tools and scripts

## Using Commons Resources

Organizations can:
1. **Reference**: Link to commons resources
2. **Fork**: Copy to your org folder with attribution
3. **Contribute**: Submit improvements via PR
4. **Claim**: Move content to your org folder if you're the owner

## Contributing

To contribute to commons:
1. Open an issue to discuss
2. Submit PR with your contribution
3. Community reviews and merges
