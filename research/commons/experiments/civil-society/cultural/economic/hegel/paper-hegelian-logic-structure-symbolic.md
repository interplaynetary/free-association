### The Movement from Unilateral to Mutual Recognition

```
POSITING REFLECTION (Unilateral)
  │  A → B: 30%  (one-sided)
  │
  ⊗  Relationship requires TWO, not one
  │
  ↓
  │
EXTERNAL REFLECTION (Bilateral but separate)
  │  A → B: 30%
  │  B → A: 30%
  │  Two acts, not one relationship
  │
  ⊗  No principle of unity
  │
  ↓
  │
DETERMINING REFLECTION (Synthesis via min)
  │
  MR(A,B) = min(A→B, B→A)
  │
  WHY MINIMUM? (Absolute necessity from Master-Slave dialectic)
  │
  ├─ Master: receives recognition, doesn't give
  ├─ Slave: gives recognition (coerced), doesn't receive
  ├─ ∴ Master's recognition is EMPTY (from unfree slave)
  ├─ ∴ Unilateral recognition fails
  │
  ∴ MINIMUM IS ONLY OPERATOR PRESERVING MUTUAL FREEDOM
  │
  │  Alternative operators fail:
  │  • avg(A→B, B→A): A=100%, B=0% → 50% (no mutuality!)
  │  • max(A→B, B→A): Allows unilateral inflation
  │  • A→B × B→A: Treats as independent (not mutual)
  │
  │  Minimum ensures:
  │  • Neither can unilaterally inflate
  │  • Both must contribute (either=0 → MR=0)
  │  • Symmetry of freedom
  │  • Weakest link determines (respects autonomy)
  │
  │  Special case: MR(A,A) = A→A (pure self-relation)
  │
  ⊗  But: MR is still abstract possibility,
         not yet actualized as allocation
  │
  ↓
  │
ACTUALITY: Recognition → Allocation
  │
  │  allocation_i ∝ recognition_i  [proportional entailment]
  │
  │  Not causal, not instrumental, but ESSENTIAL:
  │    Recognition IS proportional claim to capacity
  │
  ↓
  │
SATISFACTION FEEDBACK (Self-Testing)
  │
  │  Recognition = hypothesis about quality
  │  Delivery = empirical test
  │  Satisfaction = result
  │
  │  ↑ satisfaction → recognition preserved
  │  ↓ satisfaction → recognition negated (reduced)
  │
  ∴ Recognition becomes SELF-CORRECTING
  │
  ⊗  But: Still external circuit (recognition vs satisfaction)
  │    Must become SELF-DETERMINING TOTALITY
  │
  ↓  TRANSITION TO CONCEPT
```
