# Experiments Directory

This is an experiments directory for testing and developing research ideas with community feedback.

## Purpose

The experiments directory provides a shared space for:
- Testing research hypotheses and methodologies
- Prototyping technical implementations
- Exploring preliminary findings
- Gathering peer feedback
- Iterating on approaches

## What Belongs Here

**Appropriate content**:
- Working papers and draft research
- Prototype implementations
- Pilot studies and exploratory analysis
- Methodology experiments
- Early-stage technical demonstrations
- Ideas ready for community feedback

**Not appropriate**:
- Finalized, peer-reviewed research (use parent directory or published/)
- Private, confidential work (use private/ directory)
- Production-ready code (graduate to parent directory)

## Context

This experiments directory is contextual to its parent directory. Content here should be related to the parent directory's focus area.

**Parent Directory**: partnerships

## Contributing

### Adding Your Experiment

1. Create a descriptive directory or file name
2. Include clear documentation:
   - Purpose and motivation
   - Methodology or approach
   - Current status
   - Questions or feedback needed

3. Open to feedback:
   - Respond to comments
   - Iterate based on suggestions
   - Document changes

### Quality Expectations

While experiments are works-in-progress, please ensure:
- Clear explanation of purpose
- Basic documentation
- Reproducible methods when applicable
- Proper attribution of sources
- Ethical research practices

## Graduation Path

When your experiment is validated and stable:

1. **For standalone research**: Move to parent directory with proper documentation
2. **For partnerships**: Transition to `research/multilateral/` with partnership agreement
3. **For publication**: Move through peer review to `research/published/`

## Organization

Organize your experiments logically:
```
experiments/
├── your-experiment-name/
│   ├── README.md           # Explain the experiment
│   ├── methodology.md      # Describe approach
│   ├── findings.md         # Document results
│   └── [implementation files]
```

## Getting Feedback

To solicit feedback:
- Open an issue describing your experiment
- Tag relevant researchers or working groups
- Participate in community discussions
- Present in convenings or workshops
